## Sobre o Projeto
Plataforma multidisciplinar ambientada em 2047, projetada para explorar um cenário de convivência harmoniosa entre a humanidade e a Inteligência Artificial, com foco em avanços tecnológicos, arte e cultura. O projeto rompe intencionalmente com o estereótipo sombrio do *cyberpunk*, apresentando uma interface luminosa (*clean*), fluida e integrada à natureza.

## Principais Entregas
- **Ecosistema Duplo (Web & Mobile):** Construção ponta a ponta de um portal de notícias web (focado na experiência de redatores) e um aplicativo mobile (focado na experiência de leitura).
- **Elemento 3D Interativo:** Implementação de um beija-flor 3D renderizado direto no navegador voando pela interface, simbolizando a integração orgânica entre tecnologia e natureza.
- **Landing Page (SyntheticA Nature):** Página focada na conscientização sobre o avanço tecnológico sustentável.
- **Identidade Visual *Light*:** Elementos flutuantes, cores vivas e uso inteligente do espaço em branco para transmitir um futuro otimista.

## Tecnologias Utilizadas
- **Design:** Figma (UX/UI, Identidade Visual)
- **Front-End Web:** HTML, CSS, JavaScript
- **3D na Web:** Three.js
- **Mobile:** React Native
- **Back-End (API):** FastAPI
